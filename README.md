# Islas de PR

Static travel website. No build step or API keys required. Netlify publish directory: `.`.

Edit `content.js` for excursions, `script.js` for page content, and `style.css` for design. Tour details were collected from the public Islas de PR Viator collections on October 21, 2026; refresh these periodically. Instagram cards link to the original reels because embedded previews were unavailable.

Run a local static server from this folder to preview. Booking and payments take place on Viator. Saved excursions and checklist items stay in the visitor’s browser.
